จมูกแมลงหวี่: ผังต่อสาย prototype

ESP32-S3 + ADS1115 + TGS2602/TGS2603 + BME688 × 2 + ปั๊มและวาล์ว ใช้ไฟ 5V จากอะแดปเตอร์ตัวเดียว GND ร่วมกันทั้งระบบ

5V 3.3V GND I²C SDA I²C SCL สัญญาณแอนะล็อก สั่งงานปั๊ม/วาล์ว

บนมือถือ เลื่อนไดอะแกรมซ้าย-ขวาเพื่อดูส่วนที่เหลือ

ตารางต่อขา

จากไปที่สายหมายเหตุ
อะแดปเตอร์ +5VESP32 5V, ฮีตเตอร์ Figaro, ขาเซนเซอร์ Figaro, ปั๊ม (+), วาล์ว (+)5Vอย่าดึงไฟปั๊ม/วาล์วผ่าน USB
อะแดปเตอร์ GNDGND ทุกจุดGNDGND ต้องร่วมกันทั้งระบบ ไม่งั้นค่าเพี้ยน
ESP32 3V3BME688 VIN ×2, ADS1115 VDD3.3VADS1115 ต้องเป็น 3.3V เพื่อคุยกับ ESP32 ได้ตรงระดับ
ESP32 GPIO8SDA ของ BME688 ×2 และ ADS1115SDAบัส I²C เส้นเดียวกัน
ESP32 GPIO9SCL ของ BME688 ×2 และ ADS1115SCLบอร์ด breakout ส่วนใหญ่มี pull-up แล้ว
BME688 #1 SDOGNDGNDaddress 0x76
BME688 #2 SDO3V33.3Vaddress 0x77
ADS1115 ADDRGNDGNDaddress 0x48
จุดแบ่งแรงดัน TGS2602ADS1115 A0แอนะล็อกระหว่าง 3.9k กับ 6.8k
จุดแบ่งแรงดัน TGS2603ADS1115 A1แอนะล็อกระหว่าง 3.9k กับ 6.8k
ESP32 GPIO4100Ω → Gate MOSFET ปั๊มสั่งงานใช้ PWM ปรับแรงลม
ESP32 GPIO5100Ω → Gate MOSFET วาล์วสั่งงานHIGH = รอบดม, LOW = รอบล้าง (กำหนดในโค้ด)

ทำไมใช้ค่าเหล่านี้

ตัวต้านทานโหลด 3.9k + 6.8kรวมกันราว 10.7kΩ ทำหน้าที่เป็นตัวต้านทานโหลดของ Figaro และแบ่งแรงดันไปพร้อมกัน แรงดันที่จุดแบ่งสูงสุดราว 5V × 6.8/10.7 ≈ 3.2V จึงไม่เกินไฟเลี้ยง ADS1115
คำนวณความต้านทานเซนเซอร์V_RL = V_A0 × 10.7/6.8 แล้ว Rs = 10.7k × (5 / V_RL − 1) ใช้ค่า Rs/R0 เทียบกับตอนอากาศสะอาด
MOSFET + 10k + 100ΩAO3400 เปิดได้เต็มที่ด้วย 3.3V (logic-level) ตัว 10k ดึง Gate ลงกราวด์ให้ปั๊ม/วาล์วปิดตอนบอร์ดรีเซ็ต 100Ω ลดสัญญาณกระชากที่ขา GPIO ถ้าใช้ IRLZ44N ก็ได้
ไดโอด 1N5819 คร่อมโหลดมอเตอร์และขดลวดวาล์วสร้างไฟย้อนตอนปิด ไดโอดดูดไว้ไม่ให้ MOSFET พัง ด้านที่มีแถบต้องหันไปทาง 5V

เช็กก่อนเสียบไฟ

ตรวจขา Figaro จากดาต้าชีตขาฮีตเตอร์และขาเซนเซอร์ของ TGS2602/2603 อยู่คนละคู่ ต่อสลับกันเซนเซอร์เสียได้ ดูผังขาในดาต้าชีตของรุ่นที่ซื้อมาก่อนบัดกรี
USB กับไฟนอกพร้อมกันถ้าเสียบ USB อัปโหลดโค้ดขณะต่ออะแดปเตอร์อยู่ ให้ตรวจว่าบอร์ดมีไดโอดกันไฟย้อน ถ้าไม่แน่ใจ ถอดสาย 5V จากอะแดปเตอร์ออกก่อน
ลองทีละส่วนต่อ I²C แล้วสแกนให้เจอ 3 address (0x48, 0x76, 0x77) ก่อน แล้วค่อยต่อ Figaro และสุดท้ายปั๊มกับวาล์ว
กินไฟโดยประมาณESP32 ตอนส่ง Wi-Fi ไม่กี่ร้อย mA ฮีตเตอร์ Figaro ตัวละไม่ถึง 100 mA ปั๊มและวาล์วรวมราว 0.5 A รวมแล้วอยู่ในงบอะแดปเตอร์ 3A
